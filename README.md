# Бот для записи в барбершоп

Telegram-бот, через который клиенты записываются на стрижку: выбирают услугу, день и время (кнопками в чате или на странице мини-приложения), смотрят свои записи и при необходимости отменяют их. Администратор (мастер) получает уведомление о каждой новой записи и отмене, а в меню мастера видит расписание, может отменять записи и закрывать время.

## Возможности

- **Запись по шагам.** Кнопка «Записаться» ведёт клиента по шагам: услуга → день → время. На любом шаге можно нажать «❌ Отмена».
- **Онлайн-запись через Mini App.** Кнопка «Записаться онлайн» открывает страницу записи ([исходники](https://github.com/seniawer/barbershop-miniapp)) прямо внутри Telegram. Бот передаёт странице занятые слоты на 7 дней вперёд, а выбор клиента принимает обратно и перепроверяет: услуга должна быть в списке, цена берётся из бота, дата и время должны быть свободны и в рабочих часах. Если слот успели занять, бот пришлёт новую кнопку с обновлённым расписанием.
- **Услуги и цены.** Мужская стрижка, стрижка бороды, стрижка + борода, детская стрижка, стрижка машинкой. Список с ценами открывается кнопкой «Услуги и цены».
- **Только свободное время.** Записаться можно на 7 дней вперёд, с 10:00 до 19:00 (последняя запись). Занятое, закрытое мастером и уже прошедшее время бот не показывает, а дни без свободных окон скрывает.
- **«Мои записи».** Клиент видит свои предстоящие записи, под каждой есть кнопка «Отменить запись».
- **База SQLite.** Записи хранятся в файле `barbershop.db`, он создаётся сам при первом запуске. База не даёт записать двух клиентов на одно и то же время.
- **Уведомления администратору.** О новой записи и об отмене бот пишет администратору: услуга, дата, время и имя клиента.
- **Меню мастера.** Команда `/admin` или кнопка «Меню мастера» в главном меню (видна только администратору). Записи на сегодня, на завтра и на неделю: у каждой записи время, услуга, цена, имя и ник клиента и кнопка «Отменить», в конце дня — число записей и сумма. Отмена — только после подтверждения, клиенту приходит сообщение «Мастер отменил вашу запись на ...».
- **Закрытие времени.** «Закрыть время»: день на 14 дней вперёд, затем «Весь день» или отдельные часы (кнопки-переключатели) и «Сохранить». Если на закрываемое время уже есть записи, бот покажет их, но не отменит. «Закрытое время» — список закрытых дней и часов с кнопкой «Открыть». Закрытое время считается занятым везде: в пошаговой записи, в мини-приложении и при проверке его данных. Полностью закрытый день в пошаговой записи не показывается, а в мини-приложении неактивен.
- **Команда `/id`** показывает ваш Telegram ID. Он нужен, чтобы указать администратора в настройках.

## Технологии

- Python 3.10+
- [aiogram 3](https://docs.aiogram.dev/) — фреймворк для Telegram-ботов (FSM для пошаговой записи, inline-кнопки)
- Telegram Mini App — страница записи на GitHub Pages, данные передаются боту через `Telegram.WebApp.sendData`
- SQLite — встроенная база данных (модуль `sqlite3`)
- python-dotenv — чтение настроек из файла `.env`

## Структура проекта

| Файл | Что внутри |
|------|-----------|
| `bot.py` | Обработчики команд и кнопок, шаги записи, онлайн-запись через Mini App, уведомления администратору, меню мастера и закрытие времени |
| `db.py` | Работа с базой SQLite: создание таблиц, записи клиентов и закрытое время |
| `requirements.txt` | Зависимости |
| `.env.example` | Образец файла с настройками |
| `deploy/barbershop-bot.service` | Служба systemd для запуска на Linux-сервере |
| `DEPLOY.md` | Инструкция по запуску на сервере Ubuntu |

## Как запустить

1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.

2. Создайте виртуальное окружение и активируйте его:

   ```bash
   python -m venv .venv
   ```

   Windows (PowerShell):

   ```powershell
   .venv\Scripts\Activate.ps1
   ```

   Linux / macOS:

   ```bash
   source .venv/bin/activate
   ```

3. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

4. Скопируйте `.env.example` в `.env` и заполните переменные:

   | Переменная | Описание |
   |-----------|----------|
   | `BOT_TOKEN` | Токен бота от @BotFather (обязательно) |
   | `ADMIN_ID` | Telegram ID администратора (мастера): ему приходят уведомления и доступно меню мастера. Если оставить пустым, бот работает без уведомлений и без меню мастера |
   | `DB_PATH` | Путь к файлу базы SQLite. Если оставить пустым — `barbershop.db` рядом с `bot.py` |

   Файл `.env` добавлен в `.gitignore`, токен не попадёт в репозиторий.

5. Запустите бота:

   ```bash
   python bot.py
   ```

6. Чтобы включить уведомления и меню мастера: напишите боту `/id`, впишите полученное число в `ADMIN_ID` в файле `.env` и перезапустите бота. Администратор должен хотя бы раз нажать `/start` у бота, иначе Telegram не даст боту написать ему первым.

Как запустить бота на сервере Ubuntu, чтобы он работал круглосуточно, — в [DEPLOY.md](DEPLOY.md).

## Меню мастера

Доступно только пользователю, чей ID указан в `ADMIN_ID`. Проверка ID стоит в каждом обработчике меню мастера и в каждой его inline-кнопке (фильтр `IsAdmin` в `bot.py`), поэтому отправить текст «Записи на сегодня» или подделать нажатие кнопки посторонний не сможет: команда `/admin` ответит «доступно только мастеру», а кнопки — сообщением об отказе.

| Кнопка | Что делает |
|--------|-----------|
| Записи на сегодня / На завтра | Записи на день с кнопкой «Отменить» у каждой, внизу — число записей и сумма |
| На неделю | То же по каждому дню с записями на 7 дней вперёд и общий итог за неделю |
| Закрыть время | Выбор дня (🔒 — закрыт целиком, 🔸 — закрыты отдельные часы), затем «Весь день» или часы. 👤 — на этот час уже кто-то записан |
| Закрытое время | Закрытые дни и часы начиная с сегодня, у каждого кнопка «🔓 Открыть» |
| Клиентское меню | Возврат в обычное меню |

Закрытое время хранится в таблице `closed_time` (создаётся сама при запуске). В таблицу `bookings` при первом запуске добавляются колонки с именем и ником клиента; уже сохранённые записи не меняются, а для них имя бот спрашивает у Telegram.

## Как устроена онлайн-запись

1. Клиент нажимает «Записаться онлайн». Бот присылает кнопку «📅 Открыть онлайн-запись» в обычной клавиатуре под полем ввода. Именно в ней, а не в inline-кнопке под сообщением: `sendData` работает только для мини-приложений, открытых из такой клавиатуры.
2. Адрес страницы собирается при каждом нажатии: `https://seniawer.github.io/barbershop-miniapp/?busy=2026-10-08_11:00,2026-10-08_15:00`. Занятые и закрытые мастером слоты страница показывает неактивными.
3. Клиент выбирает услугу, день и время и нажимает «Подтвердить запись». Страница отправляет боту JSON `{"service": "Мужская стрижка", "price": 1500, "date": "2026-10-08", "time": "12:00"}` и закрывается.
4. Бот проверяет данные, сохраняет запись в ту же базу, что и пошаговая запись, присылает подтверждение и уведомляет администратора.

Адрес страницы хранится в константе `MINIAPP_URL` в `bot.py`. Настраивать в @BotFather ничего не нужно.
